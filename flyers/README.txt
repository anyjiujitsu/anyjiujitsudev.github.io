ANY N.E. FLYERS — DEV EXPERIMENT

Install: Upload the flyers/ folder into the root of your DEV GitHub Pages repository.
Open: https://anyjiujitsu.github.io/anyjiujitsudev.github.io/flyers/
No existing files need changing. No API credentials are needed for the browser-only prototype.

WORKING NOW
- Upload a photo and see it in the preview.
- Enter event name, host, date, time, price, location, and extra information.
- Select five original deterministic design presets.
- Generate alternate variations and export a 1080x1350 PNG.
- Preserve exact input text in canvas rendering.
- Optional background-removal BETA attempts to load @imgly/background-removal from a third-party CDN; browser support, initial model download, and performance vary. It may fail; transparent PNG photo is fallback.

NOT YET INCLUDED
- Generative AI artwork or learning style language from 50 reference flyers.
- Private backend proxy, billing/limits, secure AI credentials.
- User accounts, saved generations, edit history.

This first phase validates the independently hosted user interface and compositing workflow, without exposing API keys or modifying the existing EVENTS, GYMS, COMPS, admin, or scraper modules.
